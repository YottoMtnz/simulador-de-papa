# 🥔 Simulador de Papa · Tierras Vivas

**El juego más almidonado del internet.**

Rueda, salta, empuja calabazas y cuestiona tu existencia por colinas, senderos, bosques y desiertos en este simulador 3D que nadie pidió pero todos necesitaban.

🎮 **[Jugar ahora](https://yottomtnz.github.io/simulador-de-papa/)** — gratis, sin instalación, en tu navegador (PC y móvil).

## ✨ Características

- 🌄 Terreno continuo con colinas, desniveles y un sendero sinuoso
- 🌲 Árboles con raíces, troncos curvos y follaje con viento suave
- 🌱 Hierba, flores, helechos y vegetación que se mueve
- 💡 Luz cálida de atardecer, sombras del follaje y bruma por distancia
- 🏜️ Biomas lejanos: zonas áridas, cactus, cocos y nieve
- 🎃 Física de calabazas, sistema de combos y papa dorada 🥇
- 🏆 Logros inútiles, papas NPC con nombres graciosos y tu roca mascota 🪨

## 🎮 Modos

| Modo | Descripción |
|------|-------------|
| 🌄 Salir al campo | Luz de tarde, gravedad normal y exploración libre. |
| 🌙 Noche lunar | Iluminación nocturna, estrellas y gravedad reducida. |
| 🖤 A ciegas | Pantalla sin visión, orientación por sonido. Las papas no tienen ojos. |

## 🕹️ Controles

| Acción | PC | Móvil |
|--------|----|-------|
| Rodar | WASD / Flechas | Joystick táctil |
| Saltar | Espacio | Botón SALTO |
| Cámara | Mover el ratón (sin clic) o Q / E | Arrastrar / pellizcar |
| Zoom | Rueda | Pellizca |
| Bailar | B | — |
| Logros | L | Botón 🏆 |
| Pausa (libera el ratón) | P / Esc | Botón ⏸️ |
| Silenciar | M | Botón 🔊 |
| Pantalla completa | F o F11 | Siempre (horizontal e inmersivo) |
| Mostrar FPS | F3 | — |
| Ocultar interfaz | F2 | — |

## 🖥️ Pantalla completa

El menú principal y la pausa tienen *Pantalla completa*. En el navegador no se puede superar la frecuencia del monitor.

## 📁 Archivos

- `juego.html` — el juego
- `assets/` — estilos, lógica del juego, texturas y Three.js (todo local, funciona sin internet)
- `capturas/` — imágenes del juego
- `CREDITOS.md` — licencias y procedencia de materiales

## 🛠️ Tecnología

- [Three.js](https://threejs.org/) r128
- Sonido procedural con Web Audio API
- Cero dependencias de build — solo abre el enlace y juega
