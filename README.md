# 🥔 Simulador de Papa

**El juego más almidonado del internet.**

Rueda, salta, empuja calabazas y cuestiona tu existencia en este simulador 3D que nadie pidió pero todos necesitaban.

🎮 **[Jugar ahora](https://yottomtnz.github.io/simulador-de-papa/)** — gratis, sin instalación, en tu navegador.

## ✨ Características

- 🎃 **Empuja calabazas** con física real y sistema de combos
- 🔥 **Combos** — golpes consecutivos multiplican tu gloria
- 🥇 **Papa dorada** — power-up legendario: velocidad + invencibilidad
- 🌍 **Mundo infinito** — praderas, bosques, desiertos y tundras generados sin fin
- 💥 **Partículas, confeti y screen shake** — puro jugo visual
- 📱 **PC y móvil** — teclado o joystick táctil

## 🎮 Modos

| Modo | Descripción |
|------|-------------|
| 🌄 Huerto al atardecer | Tranquilo. Para papas relajadas. |
| 🌙 Luna papística | Poca gravedad, mucho caos. |
| 🖤 Modo realista | Las papas no tienen ojos. Buena suerte. |

## 🕹️ Controles

- **WASD / Flechas** — rodar
- **Espacio** — saltar
- **Q / E o arrastrar** — girar cámara
- **Rueda** — zoom
- **Esc / P** — pausa
- **Móvil** — joystick táctil + botón de salto

## 🛠️ Tecnología

- [Three.js](https://threejs.org/) para el 3D
- Un solo archivo HTML, cero dependencias de build
- Sonido procedural con Web Audio API
